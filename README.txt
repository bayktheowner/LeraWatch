LeraWatch v0.4 — Details + Lists

Добавлено:
- тап по карточке открывает экран произведения;
- большой постер, полное описание, тип, год и рейтинг;
- кнопки «Хочу посмотреть» и «Я посмотрел(а)»;
- рабочие нижние разделы «Хочу» и «Просмотрено»;
- сохранение списков в localStorage на устройстве;
- перенос между списками и удаление;
- живой поиск через LeraWatch API сохранён.

Важно: localStorage хранится в конкретном браузере/PWA на устройстве. Облачную синхронизацию добавим отдельным этапом.
