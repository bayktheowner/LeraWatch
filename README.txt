LeraWatch v0.2 — PWA-ready frontend

Для корректного запуска разместите содержимое этой папки на HTTPS-хостинге.
Быстрый вариант с телефона: создать новый публичный репозиторий GitHub, загрузить эти файлы в корень и включить GitHub Pages (Deploy from a branch / main / root).
После публикации открыть HTTPS-адрес в Safari на iPhone -> Поделиться -> На экран «Домой».
